## 배경

「멸망한 세계의 신이 되었다」의 세계관을 쓴 캐주얼 물리 머지 퍼즐 게임입니다. 본편과는 엔진과 저장소가 다른 별도 게임입니다. 회사의 주력 엔진인 Unity 대신 Flutter·Flame·Firebase를 고른 것은, 씬 파일 없이 텍스트 코드로만 구성돼 AI 코딩 에이전트가 이슈 단위로 다루기 쉬웠기 때문입니다. 2026년 11월 기준으로 아직 정식 출시 전이며, 테스트 빌드 단계입니다.

## 내 역할

- 저장소 생성부터 Flutter 클라이언트, Firebase Functions 서버, Firestore 보안 규칙의 대부분을 맡았습니다.
- 동료는 배포 스크립트와 fastlane, 광고 실 ID와 사용자 동의(UMP/ATT), 초기 릴리스 일부를 맡았습니다.
- 인앱 결제 검증은 동료와 함께 만들었습니다.

## 개발 방식: AI 코딩 에이전트 병렬 개발

저장소 첫 주에 에이전트가 따라야 할 계약부터 만들었습니다.

- 6단계 검증 스크립트
- 설계 결정 기록(ADR) 5개
- 컨벤션 문서
- 파일 편집 뒤 자동으로 도는 훅

이후 게이트를 늘렸습니다. 변경 기록이 빠지면 막는 단계와 에셋 규격을 검사하는 단계를 더했습니다.

작업은 **이슈 → worktree → PR** 단위로 돌렸습니다. 이를 위해 도구도 직접 만들었습니다.

- 열린 이슈를 파일 겹침과 의존 관계로 나눠 병렬 레인에 배치하는 스킬
- worktree에서 PR까지 만드는 커맨드
- 릴리스 노트 커맨드

**게이트 자체도 검증했습니다.**

- 아무것도 검사하지 못한 채 통과하던 서버 게이트 3곳을 찾아 고쳤습니다.
- 검사 대상 코드를 일부러 지웠을 때 게이트가 실제로 잡아내는지 확인했습니다.

2026년 6월부터 11월까지 PR 약 263건이 머지됐습니다.

## 재화·광고 보상 경로 감사와 서버 검증

에이전트로 만든 재화·광고 보상 경로를 직접 감사했습니다. 대상은 클라이언트가 리더보드에 직접 쓰는 경로, 광고 보상 콜백에서 서명 범위 밖 파라미터를 덮어쓸 수 있는 경로, 점수 제출의 세션 처리였고, 그 결과로 다음을 넣었습니다.

- 점수 제출에 **서버가 발급하는 1회용 세션**
- 같은 요청을 다시 보내면 같은 결과를 돌려주는 **멱등 처리**
- 점수 갱신 **트랜잭션**과 리더보드 조회 인증
- 클라이언트의 점수·리더보드 직접 쓰기 차단
- 화폐 필드 "금지 목록"을 클라이언트 **쓰기 허용 목록**으로 전환하고, 에뮬레이터 규칙 테스트 추가
- 계정 삭제 시 재인증을 서버 데이터 삭제보다 먼저 하도록 순서 변경

![판을 시작하면 서버가 1회용 세션을 발급한다. 판이 끝나면 세션 ID와 함께 점수를 제출하고, 서버가 트랜잭션 안에서 세션을 읽어 판정한다. 없거나 다른 사용자의 세션이면 거절하고, 이미 제출한 세션이면 저장해 둔 같은 결과를 돌려주며, 처음 제출이면 점수·재화·리더보드를 갱신한다. 클라이언트가 점수·리더보드·화폐 필드를 직접 쓰는 요청은 보안 규칙의 쓰기 허용 목록에서 거절된다.](/image/work/god-builds-world/score-submit.svg)

## AdMob 보상 광고 서버 검증

서버 검증 모듈은 직접 작성했습니다. 서명이 걸친 구간만 파싱하고, 타임스탬프가 오래된 콜백은 거절합니다.

연결 뒤 **실서비스 콜백이 모두 400으로 실패**하는 문제가 생겼습니다.

1. **원인**: 서명을 검증하는 구간과 실제 서명 대상 구간이 percent-decode 여부에서 어긋나 서명이 맞지 않았습니다.
2. **수정**: percent-decode한 구간으로 서명을 검증하도록 고쳤고, 실제로 관측한 콜백과 당시 공개키를 테스트 픽스처로 고정했습니다.
3. **확인**: 배포 뒤 프로덕션 Firebase 환경에서 콜백의 HTTP 200 응답과 지급 원장 기록을 확인했습니다. 출시 전이라 실사용자 트래픽은 아닙니다.

## 그 밖의 문제 해결

- **Android 릴리스 빌드가 시작하자마자 크래시**: 광고 SDK가 끌어온 WorkManager의 Room 구현체 생성자를 R8이 지운 것이 원인이었습니다. 에뮬레이터 릴리스 빌드로 재현한 뒤 keep 규칙으로 막았습니다.
- **조각 이미지 메모리**: 조각 이미지를 로드할 때 원형으로 굽고 단계적으로 축소해, 디코드 메모리를 10.83MiB에서 5.14MiB로 줄였습니다 (커밋 기재값).
- **강제 업데이트**: 최소 지원 버전을 서버 설정으로 두고, 그보다 낮은 클라이언트에는 426을 돌려줍니다.
- **GA4 계측**: 광고 퍼널 이벤트를 넣었고, 사용자 동의 뒤에만 수집을 시작합니다.
